# Changelog

All notable changes to socialfi-widget are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow `cabalspy-id`.

## [0.6.0] - 2026-10-15

### Added

- Trade Feed widgets from `cabalspy-id` 0.6.0: `mountTradeFeedButton`, `mountTradeFeed`,
  `tradeFeedButtonAttributes`, `tradeFeedWidgetAttributes`, `setTradeFeedAccessToken`,
  `setTradeFeedSignInHandler`; React `<TradeFeedButton>` and `<TradeFeed>`
  (`socialfi-widget/react`). Theses widget: `frameless` and `maxHeight`.

### Changed

- Depends on `cabalspy-id` ^0.6.0.

## [0.5.0] - 2026-10-14

### Added

- First release: re-exports `cabalspy-id/widget` and `cabalspy-id/widget/react` (`socialfi-widget/react`).
